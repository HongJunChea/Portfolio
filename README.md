# Chea Hong Jun — Portfolio

Personal portfolio for **Chea Hong Jun**, a software engineering student focused on Unity gameplay, C++, AI prototypes, VR interaction, and mobile development.

**Live site:** [hongjunchea.github.io/Portfolio](https://hongjunchea.github.io/Portfolio/)

## Featured work

- Chichi's Bizarre Adventure — Unity 3D action game
- Initial C++ — C++ and DirectX game prototype
- Travel Planner Assistant — Python desktop application
- Personality-Modulated NPC Emotion Dynamics — AI dialogue prototype
- The Climb3 — interactive VR climbing experience
- Accounting Mobile App — Flutter personal finance application
- Adult Face Detection Studio — three-model image classification study

The four collaborative projects are presented from Chea Hong Jun's perspective, with contribution details based on the shared repositories and project files.

## Tech stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, and React Router.

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Deployment

Pushes to `main` deploy automatically through GitHub Actions. Vite uses the `/Portfolio/` base path during the GitHub Pages build.
